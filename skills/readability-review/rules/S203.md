# S203: 文間の論理関係が不明確

- violation: 隣接文に cause/consequence/contrast/elaboration/example/condition/sequence/independent の複数labelが同程度に成立する。
- no_violation: 接続詞がなくても関係labelが一意なら違反でない。
- uncertain: context不足で関係labelを絞れない。
- counterexample: 語彙上の因果や対比が明示的なら違反でない。
- 必要context: 隣接文と段落目的。
- forbidden shortcut: 接続詞の不在だけで判定しない。
- evidence: 競合する relation label とそれを支える入力表層を示す。
- fixtures: `S203-P01` `S203-N01` `S203-A01` `S203-C01`
