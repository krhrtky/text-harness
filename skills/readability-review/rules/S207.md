# S207: 文脈に対して抽象度が不適切

- violation: targetAudience/documentPurpose に必要な具体性と文章の抽象度が大きくずれる。
- no_violation: audience/purpose に対して抽象度が一致する。
- uncertain: `targetAudience` または `documentPurpose` がない場合は原則判断不能。
- counterexample: 専門家向け概要の意図的な抽象表現は違反でない。
- 必要context: `targetAudience` と `documentPurpose` の両方。
- forbidden shortcut: 専門用語数や文長だけで判定しない。
- evidence: contextが要求する具体性とずれる入力表層を示す。
- fixtures: `S207-P01` `S207-N01` `S207-A01` `S207-C01`
